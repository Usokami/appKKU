# Study Roulette & Flex Points Quest System (skill.md)

Skill Specification สำหรับระบบสุ่มวิชาอ่านหนังสือ จัดการเวลาเซสชัน และระบบสะสม Flex Points สำหรับอวดสถิติและจัดอันดับในกลุ่มเพื่อน

---

## 1. System Architecture & Core Capabilities

### 1.1 Subject Card Management (ระบบจัดการการ์ดวิชา)
* Create Subject Card: บันทึกการ์ดวิชาใหม่เข้าสู่ระบบ
  - รองรับชื่อวิชา, รหัสวิชา, แท็กสี (HEX), ไอคอนประจำวิชา
* Archive & Retrieve: ดึงรายการวิชาเดิมทั้งหมดที่เคยสร้างไว้
* Pool Selector: ติ๊กเลือกการ์ดวิชาเดิมเข้าสู่ Active Roulette Pool หรือนำออกชั่วคราว
  - มีระบบตรวจสอบขั้นต่ำ: ต้องมีวิชาอยู่ใน Pool อย่างน้อย 1 รายการก่อนเริ่มสุ่ม

### 1.2 Session Roulette & Time Engine (ระบบสุ่มและจัดการเวลา)
* Subject Roulette: สุ่มเลือก 1 วิชาจากรายการที่อยู่ใน Active Roulette Pool แบบ Uniform Random หรือกำหนดน้ำหนักตามความสำคัญ
* Time Configuration:
  - Manual Mode: เลือกเวลาด้วยตนเองผ่าน Preset (15, 25, 45, 60, 90, 120 นาที) หรือตั้งค่าตามใจชอบ
  - Random Mode: ให้ระบบสุ่มเวลาตาม Step ที่กำหนด (เช่น สุ่มค่าระหว่าง 20-90 นาที ขั้นละ 10 หรือ 15 นาที)
* Timer Lifecycle:
  - ควบคุมสถานะ: IDLE -> RUNNING -> PAUSED -> COMPLETED / ABANDONED
  - บันทึก Log การอ่านจริง (Real Elapsed Minutes) ป้องกันการโกงเวลากรณียกเลิกกลางคัน

### 1.3 Quest & Flex Points Engine (ระบบภารกิจและคะแนนขิงเพื่อน)
* Point Formula:
  - Base Points: คำนวณแต้มพื้นฐานจากการอ่านจบเซสชัน เช่น 1 นาที = 1 Point
  - Random Time Multiplier: โบนัสพิเศษเมื่อกล้าใช้โหมดสุ่มเวลา (+15% Point Bonus)
* 5-Hour Milestone Quest:
  - สะสมเวลารวมจากทุกเซสชันที่สำเร็จจนครบ 300 นาที (5 ชั่วโมง)
  - รับก้อนโบนัสทันทีเมื่อครบเงื่อนไข (เช่น +1,000 Flex Points)
  - รีเซ็ต Loop รอบใหม่ หรือเลื่อนขั้น Tier ภารกิจ (Tier 1: 5 ชม., Tier 2: 10 ชม.)
* Flex Showcase Generation:
  - สร้าง Payload หรือข้อมูลสรุปสำหรับแชร์: ชื่อผู้ใช้, แต้มรวมสะสม, อันดับประจำสัปดาห์, วิชาที่อ่านบ่อยสุด, สถิติต่อเนื่อง (Streak)

## 3. Detailed Workflow & State Logic

[Start]
  │
  ├── 1. Subject Management
  │     ├── เพิ่มวิชาใหม่ (Create Subject)
  │     └── เลือกติ๊กวิชาเดิมเข้า Pool (Toggle in_roulette_pool = true)
  │
  ├── 2. Subject Roulette
  │     └── กดปุ่ม "Spin" -> ดึงเฉพาะวิชาที่อยู่ใน Pool -> คืนค่า Selected Subject
  │
  ├── 3. Time Allocation
  │     ├── Mode: Manual -> ผู้ใช้กดเลือกเวลา (เช่น 45 นาที)
  │     └── Mode: Random -> สุ่มค่าเวลา (Min: 15, Max: 120, Step: 15 นาที)
  │
  ├── 4. Timer Countdown & Validation
  │     ├── เริ่มจับเวลา (Running)
  │     ├── กดยกเลิกกลางคัน -> บันทึกสถานะ Abandoned (ไม่แจกแต้ม / แจกเฉพาะเวลาจริงที่เกินเกณฑ์ขั้นต่ำ)
  │     └── อ่านครบกำหนดเวลา -> Trigger Action complete_session
  │
  └── 5. Reward Calculation & Flex Output
        ├── คำนวณ Base Points + โหมดสุ่ม Bonus
        ├── สะสมนาทีลงใน Quest 5-Hour Grind
        │     ├── หาก current_minutes >= 300:
        │     │     ├── มอบโบนัส +1,000 Flex Points
        │     │     ├── รีเซ็ตหรือทดรอบ Quest ใหม่
        │     │     └── Trigger "Quest Completed Celebration"
        └── บันทึกแต้มเข้าโปรไฟล์ -> Render Flex Card (อันดับ, แต้มรวม, สถิติ) พร้อมปุ่ม Share

## 4. API & Method Specifications

### subject_manager
* create_subject(title: string, color_code: string, icon?: string): Subject
  - สร้างการ์ดวิชาใหม่ ตั้งค่า in_roulette_pool = true เป็นค่าเริ่มต้น
* get_user_subjects(user_id: string): Subject[]
  - คืนค่าวิชาทั้งหมดของผู้ใช้เพื่อนำมาแสดงในหน้าคลัง
* toggle_pool_status(subject_id: string, in_pool: boolean): Subject
  - สลับสถานะว่าจะนำวิชานี้เข้าร่วมวงล้อสุ่มหรือไม่

### roulette_engine
* spin_subject(user_id: string): Subject
  - คัดกรองวิชาที่มี in_roulette_pool == true
  - Throw Error หาก Pool ว่างเปล่า
  - สุ่มเลือก 1 วิชาแบบสุ่มแท้จริง
* generate_study_time(mode: "manual" | "random", manual_minutes?: number): int
  - ถ้าเป็น manual: ตรวจสอบความถูกต้องของค่านาที แล้วคืนค่านั้น
  - ถ้าเป็น random: สุ่มตัวเลขจากชุด [15, 30, 45, 60, 75, 90, 120]

### session_tracker
* start_session(user_id: string, subject_id: string, duration_minutes: int, mode: string): Session
  - สร้าง Session ID และประทับเวลา started_at
* complete_session(session_id: string): SessionCompletionResult
  - คำนวณ Point ที่ได้รับ
  - ส่งต่อ Event ไปอัปเดตระบบ Quest และ Flex Profile

### flex_quest_manager
* update_quest_progress(user_id: string, added_minutes: int): QuestProgressResult
  - นำนาทีที่อ่านไปบวกกับ Quest ปัจจุบัน
  - ตรวจสอบว่าครบ 300 นาที (5 ชั่วโมง) หรือยัง
  - หากสำเร็จ: บวก reward_points และปลดล็อกสถานะ Complete
* get_flex_card_summary(user_id: string): FlexCardData
  - คืนค่า Object สำหรับนำไปเรนเดอร์ภาพหรือข้อความขิงเพื่อน:
    - total_flex_points
    - current_rank
    - total_hours_this_week
    - quest_completion_badge

## 5. Anticheat & Edge Cases Considerations

* Min-Pool Validation: ป้องกันการกด Spin หากผู้ใช้ไม่ได้เลือกวิชาใน Pool ไว้เลย หรือมีวิชาเหลือ 0 รายการ
* Early Exit Penalty: หากผู้ใช้ออกก่อนเวลาเกิน 80% ของเป้าหมาย จะไม่ได้แต้มโหมดสุ่ม และเวลานาทีจะไม่ถูกนำไปบวกใน Quest 5 ชั่วโมง
* Background Check / Tab Visibility: ตรวจจับหากปล่อยหน้าจอทิ้งไว้โดยไม่เกิด Interaction ตามที่แอปพลิเคชันกำหนด เพื่อความสมบูรณ์ของคะแนนในการนำไปขิงเพื่อน
